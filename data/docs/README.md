## Как пользоваться в курсе

1. Распакуйте архив рядом с проектом практики.
2. Индексируйте файлы из `docs/` (Markdown).
3. Для автотестов опирайтесь **только на этот snapshot**, а не на live-сайт.
4. В ответах системы указывайте, что база знаний учебная и может отличаться
   от актуальной справки Метрики.
